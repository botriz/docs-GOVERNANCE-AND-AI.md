# کیف ثریا (Suraya Wallet)

## هدف
کیف پول رسمی شبکهٔ ثریا با زبان اصلی **فارسی**، متصل به زنجیرهٔ خودمان و قابل توسعه برای شبکه‌های دیگر.

## نام برند
**Suraya Wallet / کیف ثریا**

## امکانات نسخهٔ ۱
- ساخت کیف و پشتیبان‌گیری امن
- موجودی و انتقال ARZA روی شبکهٔ ثریا
- تاریخچه تراکنش
- نمایش قوانین جاری از مرکز (نسخه‌دار)
- پیام تقدیر پس از استخراج + حمایت داوطلبانه به کیف پول مادر
- رابط فارسی

## امکانات نسخهٔ ۲
- چندشبکه‌ای (اتصال تدریجی به شبکه‌های رایج)
- NFT و سند زمین
- اعلان و امنیت پیشرفته

## صرافی (آینده)
ماژول Exchange جداگانه؛ کیف پول آماده‌سازی برای واریز/برداشت و معامله داخل اکوسیستم ثریا.

## امنیت
- کلید خصوصی در اختیار کاربر
- مرکز هوش کلید خصوصی ذخیره نمی‌کند
- همهٔ دسترسی‌های دستگاه فقط با رضایت

## قوانین
نرخ کارمزد، محدودیت‌ها و قابلیت‌ها از **PolicyEngine** سایت خوانده می‌شود و هر زمان قابل تغییر است.
