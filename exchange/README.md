# صرافی ثریا (Suraya Exchange) — نقشه راه

## وضعیت
`exchangeEnabled` در قوانین مرکز فعلاً می‌تواند false باشد تا زمان آماده‌سازی کامل.

## هدف
صرافی داخل اکوسیستم برای پاسخ به نیاز مخاطب، بدون کمبود نسبت به انتظار جهانی.

## فازها
1. واریز/برداشت ARZA از کیف ثریا
2. جفت‌های اولیه و دفتر سفارش ساده
3. اتصال تدریجی دارایی‌های دیگر
4. امنیت، نظارت، و مقیاس‌پذیری

## وابستگی‌ها
- کیف ثریا
- PolicyEngine (کارمزد و قوانین قابل‌تغییر)
- هوش مرکزی برای پایش سلامت و تجربهٔ کاربری

## اصل
هر قابلیت با امنیت و رضایت کاربر منتشر می‌شود؛ عجله بدون زیرساخت مساوی کمبود پنهان است.
